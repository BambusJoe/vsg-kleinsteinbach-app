# Sponsoren-Logos

Hier die Logo-Dateien der Sponsoren ablegen. Ich verkleinere sie und bette sie
direkt in die App ein (data-URI) – funktioniert in der gehosteten App UND im Artifact.

## So benennen
Dateiname = Firmenname in Kleinbuchstaben mit Bindestrichen, z. B.:
- `bauunternehmen-steinbach.png`
- `autohaus-pfinztal.svg`

## Format
- **PNG** (am besten mit transparentem Hintergrund) oder **SVG** – beides geht.
- JPG geht auch, wirkt aber mit weißem Kasten weniger sauber.
- Größe egal (ich skaliere), gern hochauflösend.

## Bitte dazuschreiben (in einer Nachricht an mich)
1. **Firmennamen** (exakt, wie er stehen soll) + optional Branche.
2. **Stufe**: Hauptsponsor oder Partner.
3. Optional **Link** (Website), falls die Kachel anklickbar werden soll.
